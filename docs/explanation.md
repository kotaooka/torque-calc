# 締付けトルク計算機の解説

ボルトのねじ・強度区分・摩擦係数から、VDI 2230 Blatt 1:2015 の方法で推奨締付けトルクと締付け軸力を求めます。メーカーのトルク表（Bossard、Würth など）の多くもこの方法で作られており、六角ボルト・2級のボルト穴・ν = 90% にすると、それらの表と同じ値になります。

## 推奨トルクの決め方

1. 摩擦係数が最小のとき、締付けで生じる引張り応力とねじり応力を合わせた相当応力が、降伏点の ν 倍になる軸力を求めます。これが**許容締付け軸力** FMzul です
2. 摩擦係数が最小のまま、FMzul を出すのに必要なトルクを求めます。これが**推奨締付けトルク** MA です

摩擦係数の初期値 0.12 は、メーカーのトルク表の多くと同じ「μ を 1 つに決めた」値です。範囲を入れると推奨トルクは最小の μ で決まるので、範囲の下限を下げるほど推奨トルクも下がります。

摩擦係数の最小で決めるのは、同じトルクでも摩擦が小さいほど軸力が大きくなり、降伏に近づくからです。摩擦が大きい側では、同じトルクで軸力が小さくなります（下の「軸力の範囲」）。

### 許容締付け軸力

```
FMzul = As × ν × Rp ÷ √(1 + 3 × [1.5 × (d2 ÷ dS) × (P ÷ (π × d2) + 1.155 × μG)]²)
```

- As：応力断面積 = π/4 × dS²、dS =（d2 + d3）÷ 2
- d2：有効径 = d − 0.649519 P、d3：おねじの谷の径 = d − 1.226869 P（ISO 724）
- Rp：降伏点（下降伏点 ReL、0.2% 耐力 Rp0.2、または Rpf）の最小
- ν：降伏点の利用率。VDI 2230 ではふつう 0.9
- 根号の中の 3 × [ ]² は、ねじりの応力を相当応力（ミーゼス）に換算した分です。ねじり応力の係数 kτ = 0.5 を入れてあり、締付け中にボルトの表面が少し降伏しても全体はもつ、という扱いです
- 1.155 は 1 ÷ cos 30°（メートルねじのフランク角 60° の半分）で、ねじ面の摩擦係数を、ねじの軸方向に換算するための係数です

### 締付けトルクと軸力

```
M = F × (0.16 P + 0.58 d2 μG + DKm ÷ 2 × μK)
```

- 0.16 P：ねじのリード角で軸力になる分（P ÷ 2π）
- 0.58 d2 μG：ねじ面の摩擦（d2 ÷ 2 × 1.155 μG）
- DKm ÷ 2 × μK：座面の摩擦。DKm =（dw + dh）÷ 2 は座面の摩擦の有効径です
- μG はねじ面、μK は座面の摩擦係数です。このツールでは同じ値にしています（メーカーのトルク表と同じ）

JIS B 1083 のトルク係数 K = T ÷（F × d）は、この式の括弧の中を呼び径で割ったものです。並目・μ 0.12 前後でおよそ 0.15〜0.18 になります。

### 例：M10 並目・8.8・μ 0.12・六角ボルト・2級のボルト穴

| 値 | 計算 |
|---|---|
| d2 / d3 / dS | 9.026 / 8.160 / 8.593 mm |
| As | 58.0 mm² |
| 根号の値 | 1.128 |
| FMzul | 58.0 × 0.9 × 640 ÷ 1.128 = 29.6 kN |
| DKm | (14.63 + 11) ÷ 2 = 12.8 mm |
| 括弧の中 | 0.24 + 0.628 + 0.769 = 1.637 mm |
| MA | 29.6 × 1.637 = 48.5 N·m |

メーカーの表（VDI 2230:2015）の値は 29.6 kN・48 N·m で、計算値を表の桁に丸めると一致します。

## 軸力の範囲

同じトルクで締めても、軸力は摩擦係数とトルクのばらつきで変わります。

- 最大の軸力：トルクが上限、摩擦が最小
- 最小の軸力：トルクが下限、摩擦が最大

締めたトルクのうち軸力になるのは 1 割前後で、残りはねじ面と座面の摩擦で消えます。摩擦係数が 0.08〜0.16 と倍違うと、軸力もほぼ倍違います。最大 ÷ 最小は VDI 2230 の**締付け係数 αA** に当たり、トルクで締めるときは 1.4〜1.8 程度がふつうです。軸力を揃えたいときは、摩擦の範囲を狭める（表面処理と潤滑を決める）のが一番効きます。

### トルクのばらつきと決め方

- **推奨トルクを狙い値に**：メーカーのトルク表と同じです。トルクが上にばらつくと、降伏点の利用率が ν を少し超えます（±5% なら 90% → 約 95%）。VDI 2230 の ν = 0.9 は、この程度の上ぶれを見込んだ値です
- **上限を推奨トルクに**：狙い値を MA ÷（1 + ばらつき）に下げます。上にばらついても ν を超えませんが、軸力の下限も下がります

トルクのばらつきは、締付け工具の精度（トルクレンチの JIS B 4650 / ISO 6789 の許容差、ナットランナーの工程能力）を入れてください。

## 単位

トルクは N·m・kgf·cm・kgf·m、軸力は kN・kgf で表示できます。1 kgf = 9.80665 N で換算しています（1 kgf·m = 9.80665 N·m、1 kgf·cm = 0.0980665 N·m）。

## 強度区分と降伏点

| 区分 | 降伏点の最小 [MPa] | 規格 |
|---|---|---|
| 4.6 / 5.6 | 240 / 300（下降伏点 ReL） | ISO 898-1（JIS B 1051） |
| 4.8 / 5.8 / 6.8 | 340 / 420 / 480（Rpf） | ISO 898-1 |
| 8.8 | 640（16 mm 以下）/ 660（16 mm を超える） | ISO 898-1 |
| 9.8 | 720（16 mm 以下だけ） | ISO 898-1 |
| 10.9 / 12.9 | 940 / 1,100 | ISO 898-1 |
| A2・A4-50 / -70 / -80 | 210 / 450 / 600 | ISO 3506-1（JIS B 1054-1） |

- Rpf は、ボルトの製品で引張試験をしたときの、永久伸び 0.0048d での応力です。4.8・5.8・6.8 には明確な降伏点がないため、この値を使います
- ステンレスの -70・-80 は呼び径 24 mm 以下で規定されています。それを超える径は「範囲外」と表示します（ISO 3506-1:2020 の改正で範囲が変わっている可能性があります。使う径の規格の版を確かめてください）

## 摩擦係数

VDI 2230 Blatt 1 の表 A5 は、摩擦係数を次の区分に分けています。例は目安で、同じ表面処理でも潤滑剤や相手材、締める回数で大きく変わります。

| 区分 | 範囲 | 例 |
|---|---|---|
| A | 0.04〜0.10 | 固体潤滑剤（MoS₂ペーストなど）や潤滑剤を塗った面 |
| B | 0.08〜0.16 | りん酸塩皮膜＋油、潤滑剤入りの亜鉛めっき・亜鉛フレークなど。量産ボルトで多い |
| C | 0.14〜0.24 | 潤滑しない亜鉛めっき・黒染め、潤滑剤を塗ったステンレスなど |
| D | 0.20〜0.35 | 潤滑しないステンレス、アルミとの組み合わせなど |

- 量産品で摩擦係数を指定するときは、ボルトメーカーが保証する範囲（例：亜鉛フレークで 0.09〜0.14）を入れるのが確実です
- 実測するときは JIS B 1084（ISO 16047）の締付け試験で、ねじ面と座面の摩擦係数を分けて測れます
- 同じボルトを締め直すと、表面がならされて摩擦係数が変わります。再使用するボルトは注意が必要です

## 座面とボルト穴

- 六角ボルトの座面の径 dw は ISO 4014・ISO 4017 の最小（M24 以下は部品等級 A、M27 以上は B）を使います。細目ねじの六角ボルト（ISO 8765）も同じ頭部です
- ボルト穴径は JIS B 1001（ISO 273）の 1 級（精）・2 級（中）・3 級（粗）です。メーカーのトルク表は 2 級で計算されています
- 六角穴付きボルト（ISO 4762）、フランジ付きボルト、座金を挟んでナットを回すときは、回る面が当たる外径を「座面の径」に入れてください。座面が大きいほど座面の摩擦が増え、同じ軸力に要るトルクが大きくなります
- JIS の六角ボルト（JIS B 1180 附属書）は、M10・M12・M14・M22 で二面幅が ISO と違う（17・19・22・32 mm）ものがあります。その場合も座面の径を入れ直してください

## 確かめていないこと

このツールは、ボルトそのものが降伏しない締付けトルクを出します。次のことは確かめていないので、必要に応じて VDI 2230 の計算や試験で確かめてください。

- **めねじ（ナット・タップ穴）の強度**：ナットの強度区分がボルトに合っているか、アルミや鋳鉄のタップ穴でねじ山がせん断しないはめあい長さがあるか
- **座面の面圧**：被締結物（特にアルミ・樹脂・塗装面）が座面でへこまないか。へこむと締めた後に軸力が落ちます
- **使用中の外力・疲れ・ゆるみ**：締付け軸力が、外力に対して足りるか（すべり・離間）、繰り返し荷重で疲れ破壊しないか、へたりで軸力がどれだけ落ちるか
- **伸びボルト（軸部を細くしたボルト）**：応力断面積が軸部の断面積で決まるので、この式はそのまま使えません
- **プリベリングトルク形ナット**（ナイロンナット・全金属製の戻り止めナット）：締付けトルクにプリベリングトルクが加わります。その分を足して指示してください
- **回転角法・降伏点締付け**：このツールはトルク法（弾性域で止める）だけを扱います

## 注意

- 12.9 に電気めっきをすると、水素ぜい化で締めてから数時間〜数日後に破断することがあります。10.9 でも条件によって起きます。めっきの種類とベーキングの有無を確かめてください
- ステンレスは潤滑しないとかじり（焼付き）やすく、締めている途中で回らなくなったり、ねじが破損したりします。潤滑剤を使うか、ナットの材質を変えるのが一般的です
- 図面・仕様書・顧客の規格に締付けトルクの指定があるときは、そちらを優先してください
